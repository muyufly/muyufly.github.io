Secure Token Guide

We value your security! The personal access token is **stored locally on your computer** and only used to interact with the GitHub API directly from this app.

How to generate a Fine-Grained Access Token (Recommended)
  1. Go to GitHub Settings -> Tokens (Fine-grained) -> Generate New.
  2. Name your token (e.g. Frosti Blog Contributor) and set expiration.
  3. Under Repository access, choose Only select repositories, and pick muyufly.github.io.
  4. Under Permissions -> Repository permissions:
    • Set Contents to Access: Read and Write (required to upload MD files and images).
    • Set Pull requests to Access: Read and Write (required to submit your PR).
  5. Click Generate token, copy it, and paste it into the field above!
